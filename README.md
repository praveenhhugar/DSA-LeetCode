# DSA-LeetCode

Solutions to LeetCode problems implemented in C and C++.

## Languages

- C
- C++

## Structure

Each problem is organized in a separate directory.

Each directory may contain:

- solution.c — C implementation
- solution.cpp — C++ implementation
- README.md — Problem statement, approach, and examples

## Approach

Solutions are written with a focus on:

- Clear and understandable logic
- Correct implementation
- Proper use of data structures and algorithms
- Step-by-step problem solving

## Reference

Problems are based on [LeetCode](https://leetcode.com/).
